# Foxconn Production Performance Dashboard

## Project Overview
Analyzed 3 months of manufacturing data from Foxconn production lines to track efficiency, defects, and downtime. This project is based on my 2 years experience as Production Associate in Foxconn.

## Tools Used
- Excel, Power BI, SQL (MySQL)

## Dataset
- 810 rows of production data (Jan-Mar 2024)
- 3 Production Lines, 3 Shifts
- Columns: Date, Shift, Line, Target, Actual, Defect, Downtime, Reason

## Dashboard Insights
1. Average Efficiency: 95.2%
2. Night Shift has 12% higher downtime than Morning
3. Top downtime reason: Manpower Shortage (25%)
4. Line-2 has highest defect rate (3.2%)

## SQL Analysis
- Found which line has highest defect %
- Shift-wise downtime analysis
- Top 3 defect types
